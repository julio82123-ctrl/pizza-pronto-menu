# Pizza Pronto Menu

Crie uma página inicial de cardápio digital para uma pizzaria. A página deve buscar os dados da tabela "Pizzas" no Supabase (colunas: nome, descricao, preco_p, preco_m, preco_g, imagem_url, disponivel) e exibir apenas as pizzas com disponivel = true. Cada pizza deve aparecer em um card com foto, nome, descrição e os três preços (P, M, G), com um botão "Adicionar ao carrinho". Use um layout limpo, moderno e com cara de pizzaria — cores quentes (vermelho, laranja, amarelo), fonte arredondada. Adicione um cabeçalho simples com o nome da pizzaria e um carrinho fixo no canto (ainda sem funcionar, só visual por enquanto).
